# CrossPuck 0.5.0

CrossPuck 0.5.0 adds wired USB and Bluetooth controller support, automatic
CrossOver audio output switching, and in-app updates. It also improves recovery
when CrossPuck or a controller reconnects after Steam has started.

## New Features

- **Wired USB and Bluetooth controllers:** Use a Steam Controller over wired
  USB or Bluetooth in addition to the Puck. CrossPuck shows the active connection
  mode in the menu and selects a usable connection in Puck, wired USB, then
  Bluetooth order. Contributed by [Thomas Cool (@tomcool420)](https://github.com/tomcool420)
  in [#20](https://github.com/scryner/crosspuck/pull/20).
- **Force Reconnect:** Use `Advanced > Force Reconnect` to end the current
  controller session and discover an available connection again. Contributed
  by [Thomas Cool (@tomcool420)](https://github.com/tomcool420) in
  [#20](https://github.com/scryner/crosspuck/pull/20).
- **Hide duplicate XInput controllers:** Use
  `Advanced > Hide Duplicate XInput Controller` when CrossOver Steam exposes
  the Steam Controller twice. The setting applies to the selected Steam bottle,
  including external and CrossOver Preview bottles, while preserving existing
  ignored-device entries and other bottle settings. Contributed by
  [Thomas Cool (@tomcool420)](https://github.com/tomcool420) in
  [#21](https://github.com/scryner/crosspuck/pull/21), with configuration safety
  improvements in [#24](https://github.com/scryner/crosspuck/pull/24).
- **Follow macOS audio output:** Running CrossOver games can follow the macOS
  default output when switching between speakers and headphones without a game
  restart. `Follow macOS Audio Output` is enabled by default and remembers your
  choice. It works across running CrossOver bottles independently of the
  controller's selected bottle, and the menu shows the audio routing status.
  Requires macOS 14.2 or later and System Audio Recording permission. Audio is
  processed locally and is never saved or uploaded.
- **In-app updates:** Check for newer releases through `Check for Updates...`,
  powered by Sparkle 2. Optional automatic checks are off by default and remember
  your choice. Background checks show an `Update Available...` menu item;
  installation and restart still require your approval.

## Fixes and Improvements

- **Recover after controller disconnection or mode changes:** End stale
  sessions after the controller disappears so another connection mode can be
  discovered. Stay on the active mode until it disconnects or you request a
  reconnect. Contributed by [Thomas Cool (@tomcool420)](https://github.com/tomcool420)
  in [#20](https://github.com/scryner/crosspuck/pull/20), with fallback and
  reconnection improvements in [#22](https://github.com/scryner/crosspuck/pull/22).
- **Reconnect without restarting Steam:** After driver installation, start
  CrossPuck and Steam in either order. Starting or restarting CrossPuck while
  Steam is running triggers controller rediscovery. Connection attempts and
  teardown run outside Steam's HID calls, improving responsiveness during
  reconnection. Steam device-change notifications were also improved by
  [Thomas Cool (@tomcool420)](https://github.com/tomcool420) in
  [#20](https://github.com/scryner/crosspuck/pull/20).
- **Avoid unusable controller sessions:** Fall back to the first controller
  backend that can actually be opened and prepared, instead of stopping at an
  unavailable higher-priority connection.
- **Limit Steam discovery to supported installation paths:** Search only
  `drive_c/Program Files (x86)/Steam` and `drive_c/Program Files/Steam`, accepting
  both `Steam.exe` and `steam.exe`. This avoids scanning linked macOS Documents
  and Downloads folders and triggering unrelated permission requests. Steam
  installations outside these paths are no longer discovered recursively.
- **Sign source builds:** Set `CROSSPUCK_APP_SIGN_IDENTITY` to sign the app
  bundle with a consistent identity and retain Input Monitoring permission
  across rebuilds. Contributed by [Thomas Cool (@tomcool420)](https://github.com/tomcool420)
  in [#20](https://github.com/scryner/crosspuck/pull/20).

## Upgrading from 0.4.0

1. Install CrossPuck 0.5.0 from its DMG. Older versions without Sparkle need
   this manual installation before in-app updates become available.
2. Quit Steam, then use CrossPuck's driver install/update menu action to update
   the `hid.dll` in each Steam bottle you use. Updating the app alone does not
   replace a driver already installed in a bottle. Restart Steam afterward.
3. If you enable duplicate XInput filtering, quit all apps in that bottle and
   restart the bottle for the setting to take effect.

CrossPuck requires macOS 12 or later. Automatic audio output switching requires
macOS 14.2 or later; controller support remains available on older supported
systems. Allow System Audio Recording on first use of audio switching and Input
Monitoring for controller access. Output changes may briefly interrupt audio
while the route is rebuilt. Turning audio switching off or quitting CrossPuck
restores the game's original output.

Finish your game before installing a future in-app update: restarting CrossPuck
temporarily stops its controller bridge and audio routing.
